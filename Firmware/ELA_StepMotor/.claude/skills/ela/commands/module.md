# /ela module — 模块管理

## 功能
管理可复用模块库（A~E 五级）。自动递归解析依赖。

## 触发
```
/ela module list            # 列出所有模块
/ela module add <模块名>    # 导入模块到 ELA_LIB/
/ela module audit <模块名>  # 14 项规则审核
```

## 模块分级

| 级 | 说明 | 移植工作 |
|----|------|---------|
| A | 零 HAL 直接复用 | 复制即可 |
| B | 轻量 HAL 接口实现 | ~10 行 |
| C | 需要适配层 | ~50 行 |
| D | 需要理解后再移植 | ~100 行 |
| E | 项目专属 | 参考设计 |

## 审核项（并行 4 组子 Agent）
命名规范 / 注释规范 / 分层检查 / 中断安全 / 错误处理 / 格式检查 / 资源泄漏 / 边界条件 / 耦合度 / 内聚性 / 可测试性 / 可配置性 / 文档完整性 / 依赖完整性
