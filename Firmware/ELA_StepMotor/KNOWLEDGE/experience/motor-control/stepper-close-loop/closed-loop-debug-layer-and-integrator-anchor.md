# 闭环系统调试: 数据层修复后仍在的分层排查, 与自由积分器的输出锚定

**适用**: 带反馈的闭环系统(电机位置/电流环、伺服、电源); 症状=到位后抖动/漂移/极限环; 控制参考由代码生成(查表/标定/模型换算)
**步骤**: 1. 修复"参考/数据层"(表、标定、换算)后症状仍在→把怀疑转向"控制层", 不要在已修复层反复调参 2. 对照差分定位: 取同条件下"正常 vs 异常"样本逐字段对比, 差异最大的字段指向故障层 3. 查闭环输出是否"自由积分": 只做增量累积、无绝对基准→必然漂到任意状态, 修复=锚定到"当前状态对应的参考值"+有界小校正 4. 稳定判据: 输出落在系统平衡点等价类(周期/对称产生的等价集合)才叫稳定, 看等价不看绝对值
**关键参数**: 锚=参考模型输出(查表/标定); 校正限幅=按容差比例取小(温和); 基准/原型参数在约束变化(控制率/实时预算)时整体重标, 不可照搬
**陷阱**: 单点抽查掩盖结构错误(验证须测关系性质: 单调/间距/跨边界连续); 修完A层症状仍在却继续在A层调参(先对照差分再动手); 自由积分输出停在非平衡点→误差持续饱和→大振幅极限环(来回摆/满量程扫); 修复未按"输出落在平衡点等价类"实测即宣布完成
