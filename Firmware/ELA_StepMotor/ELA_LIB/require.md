## MT6816 SPI 读取协议（4线，SPI Mode3）
- 读角度：帧 1 发送 `(0x80|0x03)<<8 = 0x8300` 读 0x03 寄存器 → 返回角度高 8 位（Angle<13:6>）
- 帧 2 发送 `(0x80|0x04)<<8 = 0x8400` 读 0x04 寄存器 → 返回角度低 6 位（Angle<5:0>）+ bit1 弱磁报警 + bit0 偶校验位
- 拼装：`raw_data = (reg03<<8)|reg04`；`raw_angle = raw_data>>2`；偶校验覆盖整字
- 典型实测：静止时输出 `raw:0x66C0 ang:6576 v:1 m:0`（m=0 表示磁场正常）

## CAN 通信协议（500kbps，标准帧 11bit ID，8 字节数据，小端）
### 帧 ID 分配
| 方向 | ID | 说明 |
|------|-----|------|
| 主机→电机 | 0x201 | 控制帧 |
| 主机→电机 | 0x202 | 参数帧 |
| 主机→电机 | 0x203 | 状态查询帧 |
| 电机→主机 | 0x301 | 状态应答帧 |

### 控制帧 0x201（数据[0]=功能码）
| 功能码 | 功能 | 数据区 | 说明 |
|--------|------|--------|------|
| 0x01 | 使能 | - | 使能电机闭环保持 |
| 0x02 | 失能 | - | 失能并制动 |
| 0x10 | 绝对正转 | [1..4]=int32 目标位置（编码器计数） | 正向旋转到绝对位置 |
| 0x11 | 绝对反转 | [1..4]=int32 目标位置（编码器计数） | 反向旋转到绝对位置 |
| 0x20 | 相对正转 | [1..4]=int32 位移量（编码器计数） | 当前位置 + 位移 |
| 0x21 | 相对反转 | [1..4]=int32 位移量（编码器计数） | 当前位置 - 位移 |

### 参数帧 0x202（数据[0]=参数码）
| 参数码 | 参数 | 数据区 | 说明 |
|--------|------|--------|------|
| 0x01 | 驱动电流 | [1..2]=uint16（mA） | 运动时电流 |
| 0x02 | 保持电流 | [1..2]=uint16（mA） | 到位保持电流 |

### 状态查询帧 0x203（0 字节数据）

### 状态应答帧 0x301（电机→主机）
| 字节 | 内容 | 说明 |
|------|------|------|
| 0 | 状态字 | bit0=使能 bit1=到位 bit2=超时 bit3=过流 |
| 1..4 | 当前位置 | int32 编码器计数 |
| 5..6 | 当前电流 | uint16 mA |

### 定位单位
- 位置/位移单位：编码器计数（16384 计数/圈，1 计数 = 0.022°）
- 位置为单圈绝对位置，取模 16384 后执行；位移为相对量可任意
