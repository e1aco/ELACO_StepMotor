PID 逐 tick 推演 (Kp=8, Ki=1, 限幅=2000mA)
===============================================

初态: 位置=0, 目标=10000, 速度=0, I=0, I_round=0

【tick 1】
  error = 10000 - 0 = 10000
  P     = 8 x 10000 = 80000 → 限幅 2000
  I:    I_round += 1 x 10000 = 10000
        integral_step = 10000 >> 10 = 9
        I_round -= 9 << 10 = 10000 - 9216 = 784
        I_term += 9 → I_term = 9
  总和  = 2000 + 9 = 2009 → 限幅 2000
  电流  = 2000 mA
  电机  加速度=2000/500=4, 速度=0+4=4, 位置=0+4=4

【tick 2】
  error = 10000 - 4 = 9996
  P     = 8 x 9996 = 79968 → 限幅 2000      ← 还在饱和
  I:    I_round += 1 x 9996 = 784 + 9996 = 10780
        integral_step = 10780 >> 10 = 10
        I_round -= 10 << 10 = 10780 - 10240 = 540
        I_term += 10 → I_term = 19
  电流  = 2000 mA                            ← 限幅，I 在偷偷累积

【...中间省略几百个tick，电流一直饱和在2000...】
  电机在全力加速，位置追近目标
  I_term 每 tick 加 9~10 → 几十个tick后长到几百

【tick ~380, 位置≈8300】
  error = 10000 - 8300 = 1700
  P     = 8 x 1700 = 13600 → 限幅 2000      ← 终于出饱和！
  电流  = 2000 + I_term(≈380) = 2380 → 限幅 2000   ← 但I饱和太深，还在限幅
  
【tick ~400, 位置≈8700】
  error = 1300
  P     = 10400 → 限幅 2000                  ← 电机快到了
  I_term ≈ 400
  电流  = 2000 + 400 = 2400 → 限幅 2000     ← 还在饱和

  问题：I太大了！到目标时 I_term ≈ 500
       即使error=0，I_term 还输出 500mA
       电机冲过头 → error变负 → I开始回收(慢)
       再冲回来 → 震荡好几轮才稳定

这就是为什么 Ki 不能太大，以及为什么需要 D——D 能在冲过头之前刹车。
