# 工作流: 标准档开发（standard）

> 被 `new.md` 在 standard 档时引用。

**适用**：跨模块特性、需设计但非系统级
**产出**：`discussion/<slug>/brainstorm.md` + `milestones.md`

---

## 阶段 1：头脑风暴

1. **调研**：调用 `codegraph_explore` 分析现有代码中相关模块的结构
2. **方案对比**：列出 2-3 个候选方案，每方案带：
   - 实现思路
   - 优缺点
   - 推荐指数
3. **推荐**：给出明确推荐方案及理由
4. **用户确认**：等用户选择/调整

## 阶段 2：里程碑拆分

1. 将选定方案拆为 ≤5 个里程碑（S1-S5）
2. 每个里程碑含：目标、改动文件、验收标准
3. 输出 `milestones.md`
4. 引导从 S1 开始：`/ela new --light "S1: <描述>"`
