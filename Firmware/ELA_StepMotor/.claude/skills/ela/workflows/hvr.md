# 工作流: HVR（人-机验证）

> 被 `verify.md` 引用。
> 人-AI 协作验证周期：AI 编译/分析 → 人类操作 → AI 检查结果 → 通过/失败。

---

## HVR 模板

```
━━━ 人工验证请求 ━━━━

步骤: S<N> — <标题>
文件: <变更文件列表>

验证内容:
□ 功能完整性    ─── <列出需要人工验证的功能点>
□ 边界条件      ─── <异常输入/边界值>
□ 硬件对齐      ─── <引脚/时序/电平>
□ 编译结果      ─── <0 error, 0 warning>

验证方法:
1. <操作序列>
2. <观察要点>

预期结果:
<通过标准>

━━━━━━━━━━━━━━━━
```

## 验证流程

```
AI 输出 HVR    →    人类操作    →    AI 检查结果
                              ↕
                     通过？→ YES → result.md 推进
                            → NO  → 诊断 → 修复 → 重新验证
```

## 诊断流程（验证失败时）

发现问题 → ① 诊断根因 → ② 推荐 2-3 个方案 → ③ 等用户确认 → ④ 修复
禁止擅自修改代码。
