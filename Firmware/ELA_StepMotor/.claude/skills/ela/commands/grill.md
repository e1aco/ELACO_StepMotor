# /ela grill — 需求盘问模式

## 功能
一问一答澄清需求，问题带推荐答案。自动写 CONTEXT.md（术语表）+ ADR。

## 触发
```
/ela grill <需求描述>
```
或在 `/ela new` 中自动触发。

## 核心原则

| 原则 | 说明 |
|------|------|
| **一问一答** | 每次只问一个问题，带推荐答案和理由 |
| **先查代码** | 能读代码解决的问题不问用户 |
| **术语精炼** | 模糊术语达成一致后立即写 CONTEXT.md |
| **追问到底** | 深度优先，一个分支走到底再开新分支 |

## 模糊信号（检测到任一即盘问）

- 歧义词："优化""改进""增强"
- 隐含前提："加个保护"（过流？过温？堵转？）
- 多方案未选："加CAN通信"（CANopen？J1939？自定义？）
- 与代码矛盾：已有类似功能但需求说"新做"
- 用户不确定："大概""之类的""可能"

## 产出物

- **CONTEXT.md**：项目根目录，领域术语定义
- **docs/adr/**：架构决策记录（ADR-YYYYMMDD-xxx.md）
