# /ela disc — 深度讨论模式

## 功能
5 阶段系统级讨论。强制完成约束，禁止讨论完成前编码。

## 触发
```
/ela disc <主题>
```
或在 `/ela new --deep` 中自动触发。

## 5 阶段

| 阶段 | 产出 | 内容 |
|------|------|------|
| 1. 拆分 | `split.md` | 拆为独立子系统，>3 时并行子 Agent |
| 2. 需求对齐 | `req.md` | 接口签名、数据结构、依赖关系 |
| 3. 硬件对齐 | `hardware.md` | 引脚/外设/中断/资源预算（嵌入式） |
| 4. 头脑风暴 | `brainstorm.md` | 2-3 方案对比 + 推荐 |
| 5. 里程碑 | `milestones.md` | ≤5 个子步骤，每步可独立验证 |

**逃生口**：用户说"编码"跳过所有阶段。
